# أكاديمية الميكاترونكس اليمنية 🎓
### دليل التصدير والنشر السلس على Vercel مع قاعدة بيانات Neon PostgreSQL

تم تجهيز هذا المشروع بالكامل ليعمل بسلاسة على منصة **Vercel** كـ Full-Stack Serverless Web Application، مع قاعدة بيانات خارجية دائمة عبر **Neon PostgreSQL**.

---

## 🚀 خطوات النشر على Vercel من البداية حتى التشغيل

### الخطوة 1: تصدير المشروع إلى GitHub
1. من واجهة **Google AI Studio**، قم بتصدير المشروع (Export to GitHub).
2. اختر حسابك ومستودعك الجديد في GitHub.

---

### الخطوة 2: إنشاء قاعدة بيانات Neon PostgreSQL (مجانية ودائمة)
1. توجّه إلى موقع **[Neon Console](https://console.neon.tech)** وسجّل الدخول.
2. أنشئ مشروعاً جديداً (مثال: `mechatronics-academy`).
3. من لوحة تحكم Neon (Dashboard)، انسخ رابط الاتصال **Connection String** المخصص (تأكد من اختيار نوع **Pooled** أو الرابط المباشر):
   ```text
   postgresql://username:password@ep-cool-fog-123456-pooler.region.aws.neon.tech/neondb?sslmode=require
   ```

---

### الخطوة 3: ربط المشروع ونشره على Vercel
1. توجّه إلى **[Vercel Dashboard](https://vercel.com/dashboard)**.
2. اضغط على **Add New...** ثم **Project**.
3. اختر مستودع المشروع من حسابك على GitHub واضغط **Import**.
4. في شاشة إعداد المشروع (Configure Project):
   - **Framework Preset**: اختر **Vite** (أو Other).
   - **Build Command**: اتركه تلقائياً (`npm run build`).
   - **Output Directory**: اتركه تلقائياً (`dist`).
5. في قسم **Environment Variables** (متغيرات البيئة)، أضف المتغيرات التالية:

| اسم المتغير (Variable Name) | الوصف | القيمة المقترحة |
| :--- | :--- | :--- |
| `DATABASE_URL` | رابط الاتصال بقاعدة بيانات Neon PostgreSQL | الرابط المنسوخ من Neon |
| `JWT_SECRET` | مفتاح التشفير الآمن لجلسات الطلاب والإدارة | نص عشوائي قوي (32 حرفاً أو أكثر) |
| `GEMINI_API_KEY` | مفتاح Google Gemini للذكاء الاصطناعي (شرح الدروس والاختبارات) | مفتاح Gemini API الخاص بك |
| `ADMIN_PASSWORD` | كلمة مرور حساب مدير الأكاديمية | كلمة المرور التي تختارها (افتراضي: A7820600) |
| `WHATSAPP_NUMBER` | رقم الواتساب الرسمي المعتمد للتواصل والتفعيل | `785502919` |
| `NODE_ENV` | بيئة التشغيل | `production` |

6. اضغط على زر **Deploy**.

---

## ⚙️ كيف يعمل المشروع تلقائياً بعد النشر؟

1. **التهيئة التلقائية لقاعدة البيانات (Auto-Migration & Seeding)**:
   - بمجرد تشغيل المشروع، يتصل الخادم تلقائياً بقاعدة بيانات Neon.
   - يتم إنشاء الجداول المخصصة للطلاب والاشتراكات والأكواد تلقائياً.
   - يتم تفعيل الحساب الإداري المعتمد، وتوليد حزم أكواد التفعيل الجاهزة (الشهرية `AS-` والسنوية `AB-`).

2. **نظام التسجيل والدخول**:
   - **التسجيل**: الاسم، رقم الهاتف، الجامعة، المستوى الدراسي، وكلمة المرور.
   - **تسجيل الدخول**: برقم الهاتف وكلمة المرور فقط.
   - **أكواد التفعيل**: تُستخدم لمرة واحدة فقط لتأكيد الاشتراك الأول وترتبط برقم هاتف الطالب.

3. **لوحة تحكم الإدارة المحمية**:
   - الوصول عبر أيقونة الدرع في الهيدر أو الرابط السفلي `/` بإدخال كلمة مرور الإدارة.
   - تتيح توليد أكواد اشتراك شهرية (`AS-` مدة 30 يوماً) وسنوية (`AB-` مدة 365 يوماً)، وتفعيل/تعطيل حسابات الطلاب ومراقبة حالة الاتصال بقاعدة بيانات Neon.

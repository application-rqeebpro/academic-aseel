# دليل تثبيت تطبيق أكاديمية الميكاترونكس اليمنية على الهاتف (Android APK)

تم إعداد وتجهيز مشروع Android بالكامل داخل مجلد `/android` ومزامنة أحدث ملفات الواجهة من `/dist`.

### التحقق من تكامل المشروع:
1. قاعدة بيانات **Neon PostgreSQL** متصلة وتعمل بكامل بياناتها (15 طالباً، 14 اشتراكاً، 207 أكواد تفعيل).
2. أكواد التفعيل المعتمدة: **AS-** (شهري) و **AB-** (سنوي).
3. خدمة **Gemini** وخاصية "اشرح لي" الهندسية خطوة بخطوة مدمجة بالكامل.
4. أذونات الكاميرا والإنترنت والملفات ووضع Portrait كلها مجهزة في `AndroidManifest.xml`.
